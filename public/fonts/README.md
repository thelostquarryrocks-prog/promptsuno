# Canvas label font

`Geist-Regular.ttf` is the unmodified font bundled with Next.js 16.3.6 at
`next/dist/compiled/@vercel/og/Geist-Regular.ttf`. SHA-256:
`bde046ddd9f20be35b0bd56cc79eb752b967fb6661a3fe76cb067bb09f871d76`.

Source project: https://github.com/vercel/geist-font. The accompanying `OFL.txt`
is its SIL Open Font License. Canvas catalog labels use this local asset to avoid
blocking scene readiness on the default Troika external font resolver.
